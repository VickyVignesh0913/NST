Step 1 Set up Next.js project with Tailwind. Configure brand colors: Primary Blue #1565C0, Accent
#2196F3, Dark #0D1117.
Step 2 Build Navbar component — logo, nav links, search icon, login button. Active state in blue. Mobile
hamburger menu.
Step 3 Build Footer component with 3 columns: logo, legal links, app download badges.
Step 4 Build AuthModal component — two states: Login (phone/email input) and Signup (full registration
form). Smooth backdrop + slide-in animation.
Step 5 Build CourseCard component — thumbnail, title, short description, price (new/old/discount badge),
View Details CTA. Support 'NEW' badge and 'FREE' variant.
Step 6 Build Paid Courses page — grid of CourseCards using data/courses.json. Blue hero banner
header.
Step 7 Build Free Courses page — CourseCard variant with View Content + View Details CTAs.
Step 8 Build Recorded Courses page — filtered view of recorded-type courses.
Step 9 Build Homepage — BrowseGrid, Featured horizontal scroll, Testimonials carousel, About Us,
Contact form.
Step 10 Build Purchases page — auth-gated, tab switcher (Paid / Test Series), search, empty state.
Step 11 Polish: animations, mobile responsiveness, SEO meta tags, performance optimisation.
Design Principles — Premium UI
n Do NOT replicate the generic Appx template look — build something premium and custom
n Use the brand blue (#1565C0) as primary, white backgrounds, dark text (#0D1117)
n Course cards should have subtle shadow, hover lift effect, rounded corners (12px)
n Hero banners on listing pages: bold uppercase white text on solid blue background (as in original)
n Testimonials: card carousel or masonry grid — show name prominently, quote in italic
n Auth modals: centered, white card, dark overlay backdrop, smooth Framer Motion animation
n Typography: Inter or Geist font — bold headings, regular body, consistent scale
n Mobile-first: all pages must be fully responsive and usable on mobile
n Page transitions: subtle fade between routes using Next.js layout animations
